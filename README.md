# ♻️ Recicla Água Santa

Uma plataforma Civic-Tech focada na educação ambiental e na facilitação da logística de descarte consciente de resíduos para a comunidade.

Projeto desenvolvido com foco na aplicação prática de tecnologia para resolução de problemas sociais, alinhado aos princípios do ODS 12 (Consumo e Produção Responsáveis) da ONU.

## 🎯 O Projeto
O descarte incorreto de resíduos, como óleo de cozinha, lixo eletrônico e plásticos, impermeabiliza o solo, entope galerias pluviais e contribui diretamente para desastres climáticos locais. O **Recicla Água Santa** atua como uma ponte entre os moradores e os pontos oficiais de coleta, desmistificando o processo de reciclagem através de uma interface limpa, acessível e direta.

## ✨ Funcionalidades Principais
* **EcoMapa Dinâmico:** Um sistema inteligente de buscas cruzadas (por material e região) construído em JavaScript, conectando o usuário instantaneamente a ecopontos com links automáticos para o Google Maps ou páginas oficiais.
* **Módulo Educativo:** Interface em formato "sanfona" (Toggles) com instruções sobre impacto ambiental, tempo de decomposição e preparação de materiais, utilizando linguagem acessível e impessoal.
* **Progressive Web App (PWA):** O projeto possui Manifesto e Service Worker integrados, permitindo que a aplicação seja instalada diretamente na tela inicial do smartphone, rodando offline e garantindo alta performance.
* **Design UI/UX Premium:** Interface focada em acessibilidade, contraste adequado para dispositivos móveis, feedback tátil e arquitetura de informação voltada à usabilidade.

## 🛠️ Tecnologias Utilizadas
O ecossistema do projeto foi construído priorizando performance, sem o uso de frameworks pesados, demonstrando domínio nativo da tríade web da Engenharia da Computação:
* **HTML5:** Semântica estruturada e acessibilidade.
* **CSS3:** Variáveis nativas (`:root`), flexbox, media queries e efeitos de renderização avançada (`mix-blend-mode`, pseudo-elementos).
* **JavaScript (ES6+):** Manipulação de DOM, filter arrays dinâmicos e controle de requisições de renderização.
* **PWA:** Integração com Web App Manifest e Service Workers (`sw.js`).
* **Netlify & GitHub:** Fluxo de CI/CD (Integração e Entrega Contínuas) para deploy automatizado e hospedagem serverless.
